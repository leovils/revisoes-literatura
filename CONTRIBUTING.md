# Como contribuir

Contribuições são muito bem-vindas — especialmente de orientandos que estão usando o material em suas teses.

## Tipos de contribuição

- **Correções**: erros de digitação, links quebrados, referências desatualizadas
- **Exemplos**: papers exemplares de cada abordagem (em pasta `exemplos/`)
- **Templates**: protocolos PRISMA, planilhas de extração, strings de busca
- **Scripts**: código R/Python comentado para reprodução de análises bibliométricas e meta-analíticas
- **Novas abordagens**: caso identifique abordagem relevante ainda não coberta

## Passo a passo (para alunos)

1. Fork deste repositório (botão "Fork" no canto superior direito)
2. Clone o seu fork: `git clone https://github.com/SEU-USUARIO/revisoes-literatura-mtpqi.git`
3. Crie um branch: `git checkout -b melhoria-card-narrativa`
4. Edite o(s) arquivo(s) e faça commit: `git commit -am "Adiciona exemplo de revisão narrativa em marketing B2B"`
5. Push para o seu fork: `git push origin melhoria-card-narrativa`
6. Abra um Pull Request neste repositório

## Padrão dos cards

Cada card em `cards/` segue a mesma estrutura:

- Definição (parágrafo curto)
- Quando usar (lista)
- Quando NÃO usar (lista)
- Passo a passo (lista numerada)
- Ferramentas
- Critérios de qualidade
- Armadilhas
- Exemplo
- Referência metodológica chave

Mantenha esse formato para preservar a navegabilidade.
