# Widget Interativo

Árvore de decisão em HTML estático. Em 2-3 cliques o aluno chega à abordagem recomendada.

## Local

Abra `index.html` em qualquer navegador.

## Online

Após configurar GitHub Pages (Settings → Pages → Source: GitHub Actions), o widget é publicado automaticamente em:

```
https://SEU-USUARIO.github.io/revisoes-literatura-mtpqi/
```
